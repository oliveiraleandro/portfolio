# Guia de estilo dos cases

Escreva como quem apresenta um projeto a um colega que ainda não o conhece. Use um tom cordial e profissional. Prefira palavras familiares e evite gírias. Quando um termo técnico for necessário para entender uma decisão, explique o que ele significa naquele projeto.

Prefira a ordem direta: apresente quem fez o quê. Evite elipses que obriguem o leitor a completar o sentido. “Os consultores preenchiam as avaliações. Os gestores acompanhavam os resultados” é mais fácil de acompanhar do que “Os consultores preenchiam as avaliações; os gestores, os resultados”. A primeira pessoa pode soar natural sem repetir “eu”: em “estudei o manual”, o verbo já deixa clara a autoria.

No corpo do case, evite listas e enumerações, inclusive as que aparecem dentro de uma frase. Escolha o detalhe que ajuda o leitor a entender o projeto e explique por que ele importa. No case do SEBRAE, por exemplo, o fato de os consultores preencherem as avaliações e os gestores acompanharem os resultados explica por que o projeto precisava considerar os dois grupos. Uma sequência de adjetivos sobre a plataforma diria menos.

## Sugestões para manter a consistência

Use a primeira pessoa do singular para descrever sua contribuição. Quando uma decisão for coletiva, identifique a equipe. Mantenha o mesmo nome para cada papel ao longo do relato: se apresentou alguém como “consultor”, só passe a usar “avaliador” se a distinção tiver significado no projeto.

Desenvolva uma ideia por parágrafo. Ao apresentar uma decisão, ligue a escolha à situação que a motivou. Se o projeto tinha como objetivo facilitar uma tarefa, descreva isso como objetivo. Só afirme que a tarefa ficou mais fácil quando houver evidência desse resultado.

Na revisão, leia um parágrafo em voz alta e imagine alguém conhecendo o projeto pela primeira vez. Se essa pessoa precisar voltar à frase anterior para descobrir quem agiu, nomeie o responsável. Se encontrar uma sequência de qualidades, procure uma decisão concreta que mostre o que essas qualidades querem dizer.
